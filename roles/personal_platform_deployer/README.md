# Deployer pessoal

Disabled by default. This role prepares only the root-owned CnesData ledger and
ephemeral runtime directories. It does not pull, start, prune or alter volumes.
The dispatcher verifies the three frames, original GitHub attempt and private
owner handoffs before using the shared lease. Every effect has a durable
SEND_PENDING record; unknown outcomes retain the safety state for reviewed recovery.
Deploy and rollback use exact prior checkpoint bytes, loopback slots and health
readbacks. Application data migration and historical preservation are not required.
