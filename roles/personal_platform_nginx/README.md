# Nginx pessoal

Disabled by default. Install only the named CnesData include after the reviewed
LimnoPulse smoke and host checkpoint; this role never rewrites other application
routes or reloads Nginx. Runtime changes are lease-protected and preserve the exact
previous include. Nginx listens on loopback, trusts CF-Connecting-IP only from the
loopback Tunnel peer, strips that header upstream and leaves CORS to FastAPI.
Firewall/Tunnel origin isolation is an external Ready/Production prerequisite.
